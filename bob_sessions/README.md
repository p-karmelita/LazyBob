# Bob Task Session Reports

This directory contains exported Bob IDE task session reports for hackathon judging.

## Purpose

As per hackathon requirements, all team members must export and upload Bob task session reports that demonstrate the use of IBM Bob IDE in building the LazyBob solution.

## What to Include

### Required Files
1. **Task Session Screenshots**: Screenshots of task session consumption summaries
2. **Exported Task History**: Markdown files exported from Bob IDE
3. **Session Metadata**: Information about each session

### File Naming Convention
```
YYYY-MM-DD_task-description_username.md
YYYY-MM-DD_task-description_username_screenshot.png
```

Example:
```
2026-05-15_code-analyzer-implementation_john.md
2026-05-15_code-analyzer-implementation_john_screenshot.png
```

## How to Export Sessions

### Step 1: Access Task History
1. Open Bob IDE
2. Click "Views and More Actions" (three dots)
3. Select "History"

### Step 2: Select Task
1. Ensure you're in the correct project workspace
2. Browse task history list
3. Select a task related to the project

### Step 3: Export Session
1. Click the task header to view consumption summary
2. Take a screenshot of the consumption summary
3. Click "Export task history" icon
4. Save the markdown file

### Step 4: Organize Files
1. Save screenshot and markdown file to this directory
2. Use consistent naming convention
3. Ensure no sensitive data is included

## Important Security Notes

⚠️ **CRITICAL**: Before exporting and committing session reports:

1. **Remove All Credentials**
   - API keys
   - Access tokens
   - Passwords
   - Personal information

2. **Sanitize Content**
   - Review exported markdown files
   - Remove any sensitive project details
   - Redact confidential information

3. **Verify Before Commit**
   - Double-check all files
   - Use `.gitignore` patterns for sensitive files
   - Never commit files with credentials
